# GitHub Pages Setup Guide

Your portfolio is ready! Follow these steps to make it live on the web.

## Option 1: Enable GitHub Pages (Recommended - 2 minutes)

1. **Go to your repository on GitHub:**
   - Navigate to: `https://github.com/taylorwatsonb/technical-writing-portfolio`

2. **Go to Settings:**
   - Click the "Settings" tab at the top of your repo

3. **Navigate to Pages:**
   - In the left sidebar, click "Pages" (under "Code and automation")

4. **Configure the source:**
   - Under "Build and deployment"
   - Source: Select "Deploy from a branch"
   - Branch: Select `claude/technical-writing-portfolio-011CUWHS1cpmhaJxDp2oauxg`
   - Folder: Select `/ (root)`
   - Click "Save"

5. **Wait for deployment (1-2 minutes):**
   - GitHub will show "Your site is ready to be published at..."
   - After a minute or two, it will change to "Your site is live at..."

6. **Your portfolio will be live at:**
   ```
   https://taylorwatsonb.github.io/technical-writing-portfolio/
   ```

## Option 2: Create a Main Branch Manually

If you prefer to have a `main` branch:

1. **On GitHub, go to your repository**

2. **Click the branch dropdown** (currently showing `claude/technical-writing-portfolio-011CUWHS1cpmhaJxDp2oauxg`)

3. **Type `main`** in the text field and click "Create branch: main"

4. **Go to Settings → Pages** and select the `main` branch

5. **Your site will be live at:**
   ```
   https://taylorwatsonb.github.io/technical-writing-portfolio/
   ```
